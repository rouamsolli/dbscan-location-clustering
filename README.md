# dbscan-location-clustering

## Objective

The objective of this project is to identify
dense geographical groups and detect isolated
locations using DBSCAN.

## Dataset

The dataset contains latitude and longitude
coordinates.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Algorithm

DBSCAN

## Workflow

1. Load data
2. Explore data
3. Select geographical features
4. Scale features
5. Apply DBSCAN
6. Analyze clusters
7. Identify noise
8. Visualize results
9. Evaluate clustering

## Important Parameters

- eps
- min_samples

## Results

DBSCAN identified dense geographical groups
and isolated points considered noise.
